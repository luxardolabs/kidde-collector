## Refactors

- `KiddeLoginRejectedError(KiddeClientAuthError)`: `KiddeSession.get_client` raises it for a rejected login or for missing credentials. `KiddeCollector` keeps a consecutive-rejection counter and a monotonic retry time (`config.LOGIN_BACKOFF_BASE_SECONDS` = 60, doubling to `LOGIN_BACKOFF_MAX_SECONDS` = 3600, reset on success). The expired-session 401/403 path is unchanged.
- `InfluxDBStorage.write_dataset` returns whether the cycle's points landed. The poller touches `output/.last_success` only then, and clears it at startup. The health check requires it to be fresh.
- `KiddeClient._get_events` isolates the events feed. `_refuse_redirect`: every request is sent with `allow_redirects=False`, and a 3xx raises `ClientResponseError`.
- `KiddeSession._write_owner_only`: the cookie is written to a temp file opened 0600, then renamed into place with `Path.replace`.
- `app/main.py`: `_CREDENTIALS` (PASSWORD, TOKEN) log as `****`; `_IDENTIFIERS` (USERNAME) use `_obscure`.
- Release-gate harness (`scripts/release-gates-test.sh`): it now runs in `make check`, and each clone gets its registries from a `Makefile.local` (image block v19 refuses `REGISTRY` from the command line).
- `Dockerfile.test` is removed; `make test` builds the Dockerfile's `test` stage per run.

## Fixes

- **A 422 is not landed** (KIDDECOLLE-65). InfluxDB drops every line carrying the conflicting field; the ERROR names the field.
- **Malformed device records are isolated** (KIDDECOLLE-68). The device is skipped, the others are written, and the cycle is not landed. A malformed events feed costs only the events.
- **A rejected login backs off** (KIDDECOLLE-66).
- **An unreadable cookie cache is dropped, and the same cycle logs in** (KIDDECOLLE-67). This covers bad JSON, bad UTF-8, a file the process can't read, and the wrong shape.
- **The cookie file is 0600 from creation, with an atomic replace** (KIDDECOLLE-71).
- **No redirects are followed** (KIDDECOLLE-69).
- **Credentials are masked as `****`** (KIDDECOLLE-70).
- **Tag values drop a trailing backslash; a null tag stays omitted** (KIDDECOLLE-73).
- **App code is root-owned in the image** (KIDDECOLLE-72).
- **Health requires a landed write** (KIDDECOLLE-63). A collector that can't log in or write goes unhealthy and fails smoke.
