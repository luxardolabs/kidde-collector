## Features

- **`make test` is the emitted fleet test block.** Each run starts its own compose project with a real InfluxDB 2.7 (`kidde_influxdb_test`, profile `test`, tmpfs data, readiness from its healthcheck) and tears it down pass or fail. Coverage is coverage.py branch coverage under the sysmon core, and both pytest's and the ratchet's exit codes reach make. The new `tests/test_influxdb_live.py` connects to the live server, writes a dataset and reads the tags and fields back with Flux, so `repo.test_stack_parity` holds.
- **Fleet skills added:** `/fleet-start`, `/luxpm-audit` and `/adversarial`.

## Refactors

- **One logging setup: `app/core/logging_config.py`** (`luxarch --emit logging` v6, never hand-edited), called once in the `app.main` entrypoint. It replaces `app/utils/logging.py` and its `StructuredFormatter`/`ColoredFormatter` (`repo.logging_canonical`). Modules log through `logging.getLogger(__name__)`, and the entrypoint logs as `app.main` rather than `__main__`.
- Ruff's TRY400 now sees real `logging.Logger` instances, so 14 `logger.error` calls inside `except` blocks became `logger.exception`. The traceback now lands in the JSON `exception` field. The poll loop's separate DEBUG traceback dump is gone, and the six-record InfluxDB connection-failure banner is now one record.
- **Release path, multi-arch and scanned** (`repo.release_scans_candidate`, `repo.deploy_tag_is_immutable`):
  - `release` refuses a dirty tree, an already-released `:VERSION` (fail-closed `docker manifest inspect`), and a `VERSION` not tagged at HEAD.
  - It pushes `candidate-<commit>`, scans every platform with `luxaudit --image-archive`, then promotes `:VERSION` + `:latest` by digest and runs `gh-release`.
  - `release-public` probes its GHCR destination tag and re-scans the source before promoting.
  - `version-build-push` takes the same gates, single-arch.
  - The per-platform scan loop word-splits buildx's comma-separated `PLATFORMS`. The first `make release` of this version stopped at the scan with nothing promoted; the tag was moved to the fix commit before anything was published.
  - `github-release` is renamed `gh-release` (`repo.github_release_wired`).
- **Re-emitted assets:** the hooks (0.277.0 adds `fleet-start-after-compact`), the skills fleet-start v4 and release v7, the skills (escalate v3, pin-bump v2, release v6, wrap-up v7), the claude-pointer v7, the changelog-guide v2, gitleaks v12 (identity allowlist anchored on `>$`, refusing a noreply look-alike), and guard-upgrade v1. A hand-added comment that broke the guard-upgrade asset's text match was removed.

## Infra / Ops

**PRE-DEPLOY:** if a log pipeline parses this collector's output, it now receives one JSON object per line. Caller fields sit under `attributes`, and the logger is the module path (`app.collector.poller`, …) instead of `kidde_collector`. `KIDDE_COLLECTOR_STRUCTURED_LOGS` is retired: JSON is the default, and `LOG_FORMAT=text` gives a readable terminal line. `LOG_MODULE_LEVELS` raises one module's level at runtime. `KIDDE_COLLECTOR_LOG_LEVEL` is unchanged.

- **multidict 6.7.1 → 6.9.1** (CVE-2026-104874: a reference leak in the items-view union/subtraction operators that lets a remote client grow memory without bound). It's a transitive dependency of aiohttp, and the only runtime lock change. luxaudit's lock leg flagged it, and its image leg did not, because it gates on fixable HIGH/CRITICAL only.
- **compose:** the bundled InfluxDB's `/etc/influxdb2` (an image-declared VOLUME) is now on the named volume `kidde_influxdb_config`, so `up` no longer mints an anonymous volume each run (`repo.compose_db_ephemeral_volume`).
- **Dev dependency:** `coverage` replaces `pytest-cov`.
