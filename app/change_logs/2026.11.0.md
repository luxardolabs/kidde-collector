# 2026.11.0 — 2026-11-05

Clears the HIGH apt CVE in the shipped image, makes the restart policy and OOM ranking part of compose.yml, removes personal data from the README screenshots, and moves the guards to luxarch 0.344.0 / luxlint 0.74.0 / luxaudit 0.16.0.

## Notes

- **Pre-deploy: remove `RESTART_POLICY` from `.env.prod`.** compose.yml sets `restart: unless-stopped` itself and no longer reads the variable. An `.env.prod` copied from the old `.env.example` (`RESTART_POLICY=always`) is ignored silently: compose prints no warning. In practice, a collector stopped by hand now stays down across a daemon or host restart.
- **Pre-deploy:** pin prod to `TAG=2026.11.0`.
- **Post-deploy:** the collector runs with `oom_score_adj: -500`. Whether rootless Docker or Podman accepts a negative value is untested (KIDDECOLLE-94). On rootful Docker it applies as written.
- No migrations, no dashboard changes, and no new collector settings. The cookie file in `output/` stays compatible.
- **Verified before tagging:**
  - `make check`: luxarch 76/0, luxlint 20/0, mypy 0, release gates all passed, lock audit 26 packages, 0 vulnerable.
  - 253 tests at 99.80% branch coverage (floor 99).
  - `make test-e2e` passed, with the new zero-restart check.
  - The audit leg's only red was the released 2026.10.3 image. This release replaces that image, and a fresh build carries apt 3.0.4.
