## Features

- **Dev host stack** (KIDDECOLLE-99, KIDDECOLLE-110). `make dev-deploy` / `dev-pin` run the dev stack on the dev host (`DEV_HOST := devhost`). `.env.dev`'s `COMPOSE_PROFILES=devhost` adds `kidde_dev_influxdb` and `kidde_dev_grafana`, neither publishing a host port. The Grafana joins the external `dev-edge` network pinned at 172.30.0.17, and the edge serves it by its dev name (KIDDECOLLE-111). It starts through `ops/grafana/dev-entrypoint.sh`, which refuses an empty, `admin` or placeholder password and sets `GRAFANA_PASSWORD` on every start. Its healthcheck (`/api/health`, `start_period: 120s`) fails a deploy whose Grafana was refused, and `DEV_RECREATE` recreates it when the entrypoint or provisioning changes. The collector's `environment:` blanks `INFLUX_PASSWORD` and `GRAFANA_PASSWORD`. tests/test_deploy_config.py: 19 tests.

## Refactors

- **Build context is an include list** (KIDDECOLLE-93). `.dockerignore` sends only `app/**/*.py`, `pyproject.toml`, `poetry.lock` and `VERSION`, with `__pycache__`, `.git`, `output` and env-named directories' contents excluded.
- **Grafana datasource host** comes from `INFLUX_HOST`, set per Grafana service.

## Schema / Migrations

- None.

## Infra / Ops

- **Guards:** luxarch 0.344.0 → 0.367.0, luxlint 0.79.1, luxaudit 0.18.0. Re-emitted: logging v12, logging-contract v3, image block v28, smoke v13, test block, gitleaks, check gate, hooks and skills.
- **Make:** `up`, `down`, `restart`, `logs`, `ps` and `shell` are removed. The dev host runs through `dev-deploy` / `dev-pin` / `smoke`. Elsewhere, run plain `docker compose --env-file .env.<env>` commands. `make` refuses a missing, empty or non-`YYYY.0M.MICRO` VERSION.
- **Env files:** `.env.dev.local` applies only to the local `make dev-*` stack. `.env.example` ships `TAG=2026.11.1` and documents the dev host keys.
- **dev-deploy** (image block v28) checks the dev host before it builds or pushes anything.

1. [build host, main checkout] `make release` — expect: the candidate is scanned with 0 fixable HIGH/CRITICAL, `:2026.11.1` is pushed and the GitHub Release `v2026.11.1` is created. On failure: fix the reported refusal and re-run (it refuses an already-released VERSION).
1. [build host] `docker buildx imagetools inspect --raw <registry>/luxardolabs/kidde-collector:2026.11.1`, then the same with `@<each platform digest>` — expect: every platform manifest resolves (KIDDECOLLE-98: the registry's garbage collection removed 2026.11.0's). On failure: stop and report on KIDDECOLLE-98.
1. [build host] `make release-public` — expect: `:2026.11.1` rescanned, copied to GHCR by digest, GHCR `:latest` moved to it.
1. [build host, main checkout] `make dev-deploy` — expect: `.env.dev` pinned to `sha-<commit>`, `kidde-collector`, `kidde_dev_influxdb` and `kidde_dev_grafana` healthy on the dev host, smoke PASS. Then the dev Grafana's dev name (KIDDECOLLE-111) answers `/api/health` with `200`. On failure: `make dev-pin TAG=<previous sha>`; on the first deploy there is no previous, so `DOCKER_HOST=ssh://devhost docker compose --env-file .env.dev down`.
1. [prod node] set `TAG=2026.11.1` in `.env.prod`, then `make prod-sync PROD_NODE=…` and `make prod-deploy PROD_NODE=…` — expect: `make prod-health PROD_NODE=…` healthy within two poll cycles. Rollback: `TAG=2026.11.0` is not pullable from the private registry (KIDDECOLLE-98); roll back from GHCR (`REGISTRY=ghcr.io`, `TAG=2026.11.0`).
1. \[any machine that ran the old `make up`\] `docker compose --env-file .env.dev down` — stops a collector-only stack started with the removed target, which no make target reaches now.
