# 2026.11.1 — 2026-11-16

A leaner image and simpler commands for running the collector by hand. The labels below name this collector's surfaces: Collector (the running container) and Docs (the README and guides).

## IMPROVED

- **Leaner, safer image** `Collector` — The image is built from the collector's own code and nothing else, so a stray file in your checkout can never end up inside it.
- **Plain commands for running it yourself** `Docs` — The guides now use standard docker compose commands to start, stop and follow the collector. The old make shortcuts for that are gone; if you started a collector with make up, stop it with docker compose --env-file .env.dev down.
- **Current version in the template** `Docs` — The example env file now points at this release.

## FIXED

- **Your dev account stays in the dev stack** `Collector` — The personal account file used for local testing now applies only to the local dev stack, never to production or any other setup.
