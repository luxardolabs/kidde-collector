# 2026.10.1 — 2026-10-10

A security update for the collector, plus logs that log tools can read directly.

> Surfaces: `Collector` (the running service).

## IMPROVED

- **Security update** `Collector` — This updates a networking component the collector uses to talk to the Kidde cloud, closing a published vulnerability that could let a remote server make the collector use more and more memory.
- **Logs log tools can read** `Collector` — Each log line is now a single structured record, ready for a log viewer or aggregator, and errors carry their full details on the same line. If you prefer plain readable lines in a terminal, set LOG_FORMAT=text. The old structured-logs setting is no longer needed and is ignored.
- **Reliability** `Collector` — Behind-the-scenes checks now exercise the collector against a real database, and every released image is scanned before it is published.
