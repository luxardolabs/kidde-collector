# 2026.10.2 — 2026-10-10

Cleaner, safer startup logs.

> Surfaces: `Collector` (the running service).

## FIXED

- **Every startup log line is structured** `Collector` — Configuration warnings, such as a database address that isn't encrypted or a setting outside its allowed range, were written as plain text beside the structured lines. Log tools could miss them. They now come out in the same structured form as everything else.
- **Database passwords stay out of the logs** `Collector` — If your database address includes a username and password, the collector now hides them when it logs its settings or a connection problem.
- **A bad database address says what's wrong** `Collector` — If the address is malformed, the collector now logs why it stopped instead of exiting silently.
- **Unset settings read as unset** `Collector` — A secret you haven't set now shows as unset in the startup log, rather than as a masked value that looked configured.
