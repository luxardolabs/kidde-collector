# 2026.11.0 — 2026-11-05

A security update to the image, plus a steadier restart behaviour for your collector. The labels below name this collector's surfaces: Collector (the running container) and Docs (the README and guides).

## IMPROVED

- **Restart behaviour is built in** `Collector` — Your collector always restarts after a crash or a kill, and a collector you stopped by hand stays stopped. If your production env file still sets RESTART_POLICY, remove it: it no longer has any effect.
- **Survives a low-memory host** `Collector` — When the machine runs short of memory, your collector and its database are among the last things the system stops.
- **Cleaner screenshots** `Docs` — The dashboard pictures in the README now come from the demo setup.

## FIXED

- **Security update** `Collector` — The image ships a patched package manager that closes a high-severity vulnerability found in the previous release.
- **Log lines** `Collector` — Every log line is one well-formed line, even when a device name or error message holds unusual characters.
