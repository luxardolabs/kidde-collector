# 2026.10.0 — 2026-10-02

A security release. The collector image is rebuilt with current system packages and stripped of tools it never used, closing 27 published vulnerabilities. Running the demo and test stacks is also simpler.

> Surfaces: `Collector` (the running service) and `Dashboards` (the Grafana dashboards it feeds).

## IMPROVED

- **Security update** `Collector` — The image now ships current system security fixes and no longer carries the packaging tools used to build it. That closes 27 published high-severity vulnerabilities, including in the library the collector uses for secure connections.
- **Smaller, leaner image** `Collector` — Build-only tools (the package manager and its helpers) are no longer in the image you run. Less is installed, so less can go wrong.
- **One file to run every stack** `Collector` — The demo, dev, test and collector-only stacks now come from a single compose file with a profile per stack, so there is one place to look instead of five.

## FIXED

- **Local builds no longer depend on a registry name** `Collector` — A collector you build yourself now gets a plain local name, so routine Docker cleanup can't remove an image your stack still expects. If you run your own local build, leave the REGISTRY setting empty in your environment file. If you pull a released version, nothing changes.
